# DIPLOCRAFT v1.0.0 — Release Candidate Comercial

## Status
Esta build está preparada para teste público controlado.

## Como publicar
1. Extraia o ZIP.
2. Copie os arquivos por cima do repositório.
3. Não apague nem substitua a pasta `assets/` existente no GitHub.
4. Faça commit.
5. Aguarde deploy no Vercel/GitHub Pages.
6. Teste em navegador desktop e mobile.

## Teste obrigatório
- Console sem erro vermelho.
- Novo Jogo funciona.
- Continuar funciona depois de salvar.
- Áudio liga após clique do usuário.
- Tutorial abre.
- Abas principais carregam.
- Loja simulada abre.
- +1 dia e +7 dias funcionam.
- Mobile permite rolagem e navegação.

## Observação
Esta build é NO_ASSETS. Ela depende dos assets já existentes no repositório.
