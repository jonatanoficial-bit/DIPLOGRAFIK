# Etapa v0.8.2 — Áudio e Clima Cinematográfico

Esta etapa adiciona áudio sem exigir assets:
- música ambiente sintética;
- efeitos de clique;
- efeitos por evento;
- controle de volume;
- toggle de música e SFX;
- mood de crise/eleição.

## Observação
Como o pacote é NO ASSETS, nenhum arquivo de áudio foi incluído. O som é gerado pelo navegador via Web Audio API.
