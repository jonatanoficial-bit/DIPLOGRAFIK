# Fase 2 — Clean Base

## Objetivo
Transformar a Fase 1 recuperada em uma base de projeto confiável, eliminando código paralelo, conteúdos e documentos de outro produto, além de reconstruir os registros oficiais.

## Alterações
- Removidos três arquivos JavaScript órfãos/duplicados.
- Removido o pacote de conteúdo não relacionado e recriado o conteúdo-base político.
- Removida a documentação antiga conflitante e criada documentação oficial.
- Corrigidos 404, favicon, webmanifest, identidade e metadados.
- Regenerados manifestos de assets usando somente os arquivos existentes.
- Adicionados testes de grafo fechado e higiene do projeto.

## Não alterado
Regras, números, telas e save do gameplay da Fase 1 foram preservados para reduzir risco de regressão.
