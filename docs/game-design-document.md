# Medical Simulator - Vale Edition

Build v0.5.0 consolida a Fase 5 do TDD: progressão, retenção, XP, missões, reputação, desbloqueios e modo simulador.

- Jogo web estático pronto para GitHub Pages.

- Save local versionado.
- HUD com build visível.
- Core loop clínico: anamnese, exames, procedimentos, hipóteses, diagnóstico e pós-consulta.
- Meta loop: XP, créditos, nível, reputação, missões, ranking local e aprendizagem.
